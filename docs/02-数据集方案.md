## 1. 两阶段训练与对比（路线 D 核心）

| 阶段 | 标签来源 | 说明 |
|---|---|---|
| **v1 伪标签训练** | MediaPipe Hands 自动预标注，原样训练 | 建立基线；标签质量受教师上限约束 |
| 人工修正 | **X-AnyLabeling**（推荐：桌面版直接打开 YOLO 目录改 txt，支持模型辅助）/ **CVAT**（YOLO 1.1 zip 导入导出，适合团队协作） | 修正错检/漏检/关键点偏移；只改标签内容，**不改划分** |
| **v2 修正标签训练** | 修正后的标签，帧集与 v1 完全相同（`split.json` 固化） | 公平对比 |
| **对比** | `tools/compare_models.py`：两版 `best.pt` 在同一 test 集评估，输出 mAP 差异表 | 产物归档 `runs/<时间戳>-compare/` |

## 2. 数据源与子集控制

真实装配视频来自 **Assembly101**（gated，token 访问；公开许可 CC BY-NC 4.0，仅限非商用研究演示）。

| 控制项 | 规则 |
|---|---|
| 下载粒度 | 「车型录制段（take）× 相机视角」，配置在 `config/dataset.yaml` |
| dry-run 强制 | 先列出待下载清单与总体积，**超过熔断上限（5GB/批）中止**，确认再下 |
| 当前批次 | 8 段体量最小的录制 × 第三人称视角 v1（C10095），共约 2.55GB；`with_poses: false`（路线 D 不需要官方 3D 姿态 JSON） |
| 数据不足时 | **继续按体量最小优先取段**（每批 ≤5GB），直到 §3 门槛达标 |

## 3. 数据量门槛与 7/2/1 划分

- **门槛**：带标注帧总量 **≥ 3000**（train ≥ 2000）；
- **划分**：每段录制按**时间连续切 7 / 2 / 1** 三块 → train / val / test，跨段合并；
  **禁止随机逐帧划分**（相邻帧近重复会跨集泄漏、虚高指标）；
- 划分由 `tools/prelabel_hands.py` 产出 `split.json` 固化；v1→v2 只允许改标签内容，不允许动划分。

## 4. 目录与训练格式

```
datasets/converted/sop_hands/
├── images/{train,val,test}/<take>_f%06d.jpg
├── labels/{train,val,test}/<take>_f%06d.txt
├── sop_hands.yaml
└── split.json                 # 划分固化（v2 不得改动）
```

`sop_hands.yaml`：

```yaml
path: datasets/converted/sop_hands
train: images/train
val: images/val
test: images/test
kpt_shape: [21, 3]      # 每手 21 关键点（x, y, 可见性）
names:
  0: right_hand         # 教师模型 handedness（非镜像输入已翻转修正）
  1: left_hand
```

## 6. 训练与验收基线

```bash
yolo pose train data=datasets/converted/sop_hands/sop_hands.yaml \
  model=yolo11n-pose.pt epochs=150 imgsz=640 batch=4 patience=30 workers=2
```

- 人体模型基线（已达成，COCO 冒烟集）：pose mAP@50 = 0.713、22.4 fps；
- **手部模型基线**：test 集 pose mAP@50 ≥ 0.60（伪标签上限受教师模型制约）；
  v2 目标：mAP 不低于 v1 且关键点错误率下降，对比报告归档。

## 7. 阶段识别数据（路线 D 扩展，决策 #17）

**两个模型分工**：手部模型（v1/v2）管「手在哪、关键点多准」（几何）；阶段分类器管「当前属于 SOP 第几步」（语义，对标 TyenJun「标注当前属于什么阶段的动作」）；规则引擎降级为保安（顺序/超时/漏步状态机 + ROI 兜底）。

**阶段定义**（3 类，按实际出现的动词收敛；映射表在 `config/dataset.yaml` 的 `stage_map`，可改）：

| 阶段 id | 名称 | 来源动词（coarse） | 8 段中的占比 |
|---|---|---|---|
| 0 | idle | 无动作段 / inspect / demonstrate（观察与展示） | 中 |
| 1 | assemble | attach / screw / position（装配类） | 大 |
| 2 | disassemble | detach / unscrew / remove（拆卸类） | 中（集中在两个 disassembly 段） |

**数据与伪标签**：官方 `coarse_labels/*.txt`（每段 7–15 个动作区间，30fps 帧号）→ 按帧展开成帧级阶段伪标签 → 与 sop_hands **同帧同划分**（复用 `split.json` + `frames_manifest.json` 做帧号对齐，30fps 标注 = 60fps 源帧 // 2）。
**修正**：与手部同流程；**只改 train**。
**训练（决策更新，agents.log 21:30）**：阶段模型为**行为检测** `yolo11n detect`——人体框 × 行为类别（0 assemble / 1 disassemble / 2 idle），伪框由人体模型+帧级阶段自动生成（`tools/prelabel_behavior.py`，数据集 `sop_behavior/`，图片经目录联接共享），人工在 X-AnyLabeling（YOLO HBB）画框修正后重训。
**验收**：test 集行为检测 box mAP@50 ≥ 85%（伪标签口径）；运行时取最大框行为 + 5 帧平滑 + 状态机输出「当前步骤」。

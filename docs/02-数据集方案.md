## 1. 约束与策略

- Assembly101 自带双手姿态与动作标注，**无需人工标注**；我的工作是把原始标注转换为 YOLO11-pose 训练格式；
- **当前实际状态**：`config/dataset.yaml` 的 `active_source=coco_val2017`（M1 流程冒烟，偏差记录见 agents.log）；HF token 就绪后切回 assembly101；
- **子集优先**：训练显存仅 4GB，且必须避免全量下载（全量数 TB）；
- 每次下载/转换作为一次运行，产物自动归档（见 01 §6）。

## 2. Assembly101 子集控制方案（防全量下载）

官方渠道：[assembly-101.github.io](https://assembly-101.github.io)，[官方下载脚本](https://github.com/assembly-101/assembly101-download-scripts)（支持按装配任务与相机视角粒度下载）。

| 控制项 | 规则 |
|---|---|
| 下载粒度 | 按「车型（take-apart toy）× 装配视频（assembly）× 相机视角」三粒度配置，配置文件在 `config/`，不硬编码 |
| dry-run 强制 | `download_subset.py` 先列出待下载文件清单与总体积，**超过熔断上限（默认 5GB）直接中止**，确认后再下 |
| 体积核算 | 实际需要的是标注帧数而非视频体积：2000–4000 帧 ÷ 5 fps ≈ 7–13 分钟素材 ≈ 单视角 1080p 约 1–1.7GB；含标注与余量预期实下 **2–3GB**。若官方打包粒度粗导致预估超 5GB，换更小的车型/更少视角，**不放宽上限** |
| 子集规模 | 1–2 种车型 × 每种 3–5 段装配视频 × 1–2 个第三人称固定视角 |
| 抽帧 | `extract_frames.py` 按 5 fps 抽帧 + 去重 + 模糊过滤，目标 **2000–4000 张标注帧**（4GB 显存训练的合理上限） |
| 具体车型选择 | 下载前从官方元数据选体量最小的先跑通（默认决策，记录在运行归档 README，可更换重跑） |

## 3. 目录与训练格式

```
datasets/
├── raw/assembly101/          # 原始子集下载（不入 git）
└── converted/
    └── sop_pose/             # 转换产物（不入 git）
        ├── images/train|val/
        ├── labels/train|val/
        └── sop_pose.yaml
```

`sop_pose.yaml`（关键点实例化方式待真实 JSON 结构确认后固定）：

```yaml
path: datasets/converted/sop_pose
train: images/train
val: images/val
kpt_shape: [42, 3]   # 双手 42 关键点（右手 21 + 左手 21）；单实例 42 或每手一实例 21，待真实 JSON 结构确认后固定
names:
  0: operator        # 作业人员（单人类）
```

转换逻辑：Assembly101 的 3D 手部关键点投影到所选相机 2D 平面 → YOLO-pose 归一化坐标。

## 4. 工具脚本（由我提供，全部位于 `tools/`）

| 脚本 | 功能 |
|---|---|
| `download_subset.py` | 按配置下载 Assembly101 子集；dry-run 核对体积；支持断点续传 |
| `extract_frames.py` | 视频抽帧（5 fps、去重、模糊过滤） |
| `convert_to_yolo_pose.py` | 3D 手部关键点 → 所选相机 2D → YOLO-pose txt，自动划分 train/val |
| `check_dataset.py` | 转换质检：关键点分布、空标统计、可视化抽查图输出到 runs/ |
| `make_demo_video.py` | 从转换数据按腕部关键点选图，生成 run 模式回放演示视频 |
| `archive_runs.py` | 按任务类型轮转 `runs/`（每类保留 5 次），归档动作 = `archive:` 提交 |

## 5. 训练快速上手（RTX 3050 4GB）与验收基线

```bash
yolo pose train data=datasets/converted/sop_pose/sop_pose.yaml \
  model=yolo11n-pose.pt epochs=150 imgsz=640 batch=4 patience=30 workers=2
```

验收基线（决策 #15 已确认）：关键点 mAP@50 ≥ 0.70（子集验证集）；Runtime 端到端 ≥ 15 fps。M1 已在 COCO 冒烟集达成（pose mAP@50 = 0.713，22.4 fps）；Assembly101 手部模型复测同一基线。

## 1. 约束与策略

- 公开数据集自带标注，**无需人工标注**；我的工作是把原始标注转换为 YOLO11-pose 训练格式；
- **子集优先**：先取单个装配任务的视频/标注跑通全流程（训练显存仅 4GB，且避免数十 GB 下载），再逐步扩大；
- 每次转换作为一次运行，产物自动归档（见 01 §6）。

## 2. 候选装配姿态数据集（★ 请选择）

以下均经核实提供真实公开下载渠道：

| 候选 | 场景与内容 | 姿态标注 | 规模 | 公开下载渠道 | 特点 |
|---|---|---|---|---|---|
| **A. Assembly101** ⭐推荐 | 101 种拼装玩具车的装配/拆卸，4321 段视频，8 视角（含固定第三人称机位，最接近工位监控视角） | 双手各 21 关节 3D 姿态 + 逐帧动作标签 | 全量数 TB，**取子集**（1–2 种车型 × 各 3–5 段视频即可起步） | 官网 [assembly-101.github.io](https://assembly-101.github.io) 提供 [下载脚本](https://github.com/assembly-101/assembly101-download-scripts) | 场景与 SOP 装配最贴合；有动作标签可与 SOP 步骤对齐 |
| **B. AssemblyHands** | Assembly101 抽帧而成的手部姿态基准（Meta 出品） | 高精度 2D/3D **手部关键点** | 官方 train/val/test 划分，可按相机子集下载 | [assemblyhands.github.io](https://assemblyhands.github.io)（工具链 [facebookresearch/assemblyhands-toolkit](https://github.com/facebookresearch/assemblyhands-toolkit)） | 以手部关键点为核心精度最高；与 A 同源 |
| **C. IKEA ASM** | 371 组家具装配，每組 3 路 RGB + 1 路深度 | 人体 3D 姿态 + 33 类原子动作 + 分割 | Google Drive 打包约 240GB，**取单一家具子集** | [ikeaasm.github.io](https://ikeaasm.github.io)（视频在共享 [Google Drive](https://github.com/IkeaASM/IKEA_ASM_Dataset)） | 人体姿态（非纯手部）；场景大、视角全景；国内访问 Drive 需网络条件 |
| **D. MECCANO** | 工业风总装流水线（玩具摩托总装），第一人称 + 第三人称双视角 | 动作/手部标签（**关键点标注稀疏**） | 20 段视频、8839 段动作，体量最小 | [github.com/fpv-iplab/MECCANO](https://github.com/fpv-iplab/MECCANO) | 最快跑通、最像产线，但姿态标注弱，需配合 A/B |

**推荐组合**：主数据集选 **A（或精度优先选 B）**，D 作为快速跑通流程的备用小数据。选择后我把对应子集的下载与格式转换脚本列入 M1。

## 4. 目录与训练格式

```
datasets/
├── raw/<数据集名>/            # 原始下载（不入 git）
└── converted/
    └── sop_pose/             # 转换产物（不入 git）
        ├── images/train|val/
        ├── labels/train|val/
        └── sop_pose.yaml
```

`sop_pose.yaml` 示例（关键点数依所选数据集而定）：

```yaml
path: datasets/converted/sop_pose
train: images/train
val: images/val
kpt_shape: [21, 3]   # A/B 手部 21 关节；若走人体姿态线则为 [17, 3]
names:
  0: operator        # 作业人员（单人类）
```

## 5. 工具脚本（由我提供，全部位于 `tools/`）

| 脚本 | 功能 |
|---|---|
| `download_subset.py` | 按所选数据集下载**指定子集**（车型/家具/视频 id 可配） |
| `extract_frames.py` | 视频抽帧（按 fps、去重、模糊过滤） |
| `convert_to_yolo_pose.py` | 原始姿态标注 → YOLO-pose txt（归一化 kpt 坐标+可见性），自动划分 train/val |
| `check_dataset.py` | 转换质检：关键点分布、空标统计、可视化抽查图输出到 runs/ |

## 6. 训练快速上手（RTX 3050 4GB）

```bash
yolo pose train data=datasets/converted/sop_pose/sop_pose.yaml \
  model=yolo11n-pose.pt epochs=150 imgsz=640 batch=4 patience=30 workers=2
```

验收基线（一期 demo）：关键点 mAP@50 ≥ 0.70（公开数据子集）；Runtime 端到端 ≥ 15 fps。
